# v0.1.1 Release Notes

Maintenance update for safer repeated first runs and output-file handling.

## Fixed

- Reject known-invalid output destinations before constructing or contacting
  the extraction provider. This includes existing targets, missing parents
  and symlink components.
- Preserve final destination revalidation, atomic no-overwrite creation and
  temporary-file cleanup. Preflight cannot guarantee that permissions or the
  filesystem will remain unchanged during extraction.
- Keep URL rejection first, existing exit codes, error envelopes, stdout
  behavior and Output Schema v0.1 unchanged.

## Repository Improvements Since 0.1.0

The source repository also includes a labeled offline-output preview, clearer
English/Japanese examples and an optional privacy-safe first-run report. The
offline helper is source-checkout-only, not an installed CLI command or a live
extraction result.

## Version Mapping

- Python package version: `0.1.1`
- Git tag: `v0.1.1`

## Install

```bash
uvx public-source-extractor@0.1.1 --version
pipx install public-source-extractor==0.1.1
```

The version command does not contact the extraction provider. Package retrieval
uses PyPI. Repository install examples and plugin fallback pins are switched
only after publication and fresh-install verification succeed.

## Provider And Safety Boundary

Extraction sends the selected public URL to Firecrawl Cloud through the
experimental `firecrawl-keyless` provider. Availability, anonymous access and
limits are not guaranteed. There is no automatic retry, provider switch or
credential discovery. Extracted content remains untrusted and important claims
need verification against original sources.

Local offline tests and package checks do not prove provider availability or
third-party adoption. This update adds no telemetry, browser automation,
authenticated-page support or background service.
