# v0.1.3 Release Notes

Maintenance update to keep the no-install quick start usable through saved
output inspection and make argument-error guidance more useful.

## Changes

- No-install examples keep using a pinned `uvx` launcher instead of assuming
  a permanent command exists in PATH.
- Saved JSON inspection preserves provenance, metadata and warnings. A failed
  extraction stops before a downstream command reads stale saved output.
- Argument errors use a fixed help hint without echoing input. Exit `2`,
  `input_rejected`, JSON shape and URL-policy rejection remain unchanged.

## Version Mapping

- Python package version: `0.1.3`
- Corresponding Git tag: `v0.1.3`

Before distribution and post-publication fresh-install checks succeed, the
repository install commands and plugin fallback stay pinned to the verified
published `0.1.2`. Updating those entry points is a separate follow-up after
verification. The PyPI description bundled with this release targets `0.1.3`.

URL-policy rejection, provider behavior, Output Schema v0.1, and exit codes
are unchanged. Extraction still sends only the selected public URL to the
experimental `firecrawl-keyless` provider. Provider availability is not
guaranteed; output remains untrusted and semantically unverified. This update
does not fetch another source to verify content or rewrite saved reports.
