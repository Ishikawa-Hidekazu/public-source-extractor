# v0.1.3 Distribution Candidate

This is an **unpublished distribution candidate**, not a release announcement.
No tag, GitHub Release or PyPI publication is created by these notes.

## Changes

- No-install examples keep using a pinned `uvx` launcher instead of assuming
  a permanent command exists in PATH.
- Saved JSON inspection preserves provenance, metadata and warnings. A failed
  extraction stops before a downstream command reads stale saved output.
- Argument errors use a fixed help hint without echoing input. Exit `2`,
  `input_rejected`, JSON shape and URL-policy rejection remain unchanged.

## Candidate And Published Versions

- Candidate package: `0.1.3`; intended future tag: `v0.1.3` (not created).
- Verified published package/tag: `0.1.2` / `v0.1.2`.
- README and plugin installation entry points stay pinned to `0.1.2` until
  publication and a separate fresh-install check succeed.
- The bundled PyPI description targets `0.1.3` and explicitly labels its
  package-index commands as post-publication only.

## Local Acceptance

Build with `python -m build`, then install the wheel in a new Python 3.11+
virtual environment. Check startup, the fixed argument error, packaged schema,
offline provider-failure fixtures and no-overwrite output behavior. Compare
wheel/sdist metadata and contents before any publication decision.

Do not resolve `public-source-extractor@0.1.3` from PyPI or use a `v0.1.3` Git
URL before publication. The same filename/version in a local build is not a
published artifact. Local/offline success does not establish live provider
availability or semantic accuracy. No new extraction is required for this
maintenance candidate.
